Bonecta ショート動画
仕様書

go2senkyo.com の活動記録から 9:16 縦型ショート動画を生成する際の参照仕様です。 実装の正は bonecta/ 配下のコード。本書は運用・レビュー用の要約です。

1080 × 1920
フレームレート
30 fps
テロップ weight

最終更新
2026-07-16

1. 出力仕様

項目値
解像度1080 × 1920（9:16）
フレームレート30 fps
コーデックH.264 / yuv420p（FFmpeg）
本編尺最大 20 秒（テロップあり）／直接動画時は最大 15 秒
エンドカード3 秒（クロスフェード 0.5 秒含む）
合計尺おおよそ 22〜23 秒

2. 処理パイプライン

go2senkyo URL
  → scraper.py      … HTML から本文・政治家情報・素材 URL を抽出
  → media_fetcher.py … 画像 / 動画 / サムネをローカル取得
  → analyzer.py     … MediaAsset 化・パターン分類・安全チェック
  → composer.py     … タイムライン・テロップ ON/OFF を決定
  → overlays.py     … バッジ・テロップ・エンドカード PNG を生成
  → renderer.py     … FFmpeg で合成 → MP4

コマンド

# 1 本（スクレイプから）
python scripts/batch_go2senkyo.py   # 未生成のみ

# 全本・再生成
python scripts/batch_go2senkyo.py --force

出力ディレクトリ（1 記事あたり）

output/go2senkyo/{slug}/
  {slug}.mp4          … 完成動画
  post.json           … スクレイプ結果・素材メタ
  ffmpeg_plan.json    … レンダリング計画（デバッグ用）
  media/              … 取得済み画像・動画
  .work/              … 中間ファイル（オーバーレイ PNG 等）

3. 素材の表示ルール（本編）

「動画」= 記事内の 直接アップロード動画（<video> / .mp4）。 YouTube・Facebook・Instagram の 埋め込みは動画本体を使わない。

記事の内容本編に表示するものテロップ
画像のみブログ画像（最大 5 枚スライド）あり
画像なし・動画なし政治家ポートレートあり
画像 + 直接動画直接動画のみ（画像は使わない）なし
直接動画のみ直接動画なし
YouTube（通常）YouTube 公式サムネ（横幅切れない pillarbox）あり
YouTube Live政治家ポートレートあり
Facebook / Instagram 埋め込み政治家ポートレートあり
画像 + YouTube 等画像 + サムネ／ポートレート（直接動画がなければ画像系）あり

素材取得

  • 画像 … 本文中の <img> をダウンロード
  • 直接動画 … mp4 をダウンロード・ffprobe で長さ・音声有無を取得
  • YouTube … 公式サムネ JPG（Live はポートレート）
  • Facebook / Instagram … 政治家ポートレートを embed_thumbnail として使用
  • フォールバック … 利用可能素材がなければ portrait_fallback.jpg
直接動画がある記事では、ブログ画像のダウンロード自体をスキップする。

4. レイアウト・画像の見せ方

4.1 共通

  • 背景ウォッシュ … #ECECE0 相当を背景レイヤーのみに薄く敷く（前景の写真・UI にはかけない）
  • 横長・小さい画像 … ぼかし背景（pillarbox）+ 中央に前景
  • 縦長画像 … 全画面に近い表示（小サイズは pillarbox）
  • 切替 … 0.5 秒クロスフェード。複数枚時は先頭 0.5 秒だけズームイン可

画角プリセット（crop_preset）

プリセット用途
default標準。YouTube サムネは 常に default（横幅全体を見せる）
wide1 枚ブログ画像の前半
close1 枚ブログ画像の後半／FB・IG・OG サムネ等

4.2 左上バッジ（全編常時表示）

要素仕様
形状黄緑（#70C040）の角丸ピル、枠線なし
左円形アバター 96px（政治家ポートレート）
右名前（白・Bold 42px）＋ フリガナ / 年齢 / 性別（白・36px）
余白左右 22px、上下 12px、アバターと文字の間 14px
位置左上 (28, 40) 付近

5. テロップ（字幕）

5.1 表示条件

  • テロップあり … 画像系本編のみ（上表参照）
  • テロップなし … 直接動画が本編にある場合

5.2 文案

  • ブログ本文を整形せず句読点で分割
  • 1 枚 最大 24 文字、最大 5 枚
  • 1 枚 4 秒 → 本編最大 20 秒
  • 最終枚は 「……（続く）」 を付与
  • URL は除去

5.3 見た目

項目値
位置画面高さの 62% 付近を中心
箱白半透明 rgba(255,255,255,200)、角丸 14px
枠黄緑 2px（#70C040）
文字色#222222
字間1px
フォントサイズ32〜50px（箱幅に自動フィット）
パディング横 30px / 縦 18px

5.4 フォント

用途フォントweight
テロップ同梱 Noto Sans JP VF500
バッジ名前・CTA同上700
メタ・注釈同上400
ファイル: fonts/NotoSansJP-VF.ttf。 OS フォントへのフォールバックなし。文字はすべて生成時に画像化して MP4 に焼き込みます。

6. エンドカード（末尾約 3 秒）

要素仕様
背景政治家肖像のぼかし + #ECECE0 ウォッシュ（UI の背面のみ）
中央上円形アバター 340px + 緑リング 12px（写真と密着）
名前黒・太字・最大 72px（幅に応じて縮小）
文言「情報発信中！」（黒・56px 目安）
CTA緑ピル 「続きは活動記録をチェック」+ 図形シェブロン（縦中央揃え）
フッター「この動画はボネクタの活動記録に基き、AIで生成しています。」（グレー・26px）
トップの帯（ヘッダーバー）はなし。

9. 安全・ブロック

analyzer.check_content_safety で NG の場合、本編・テロップなしの短尺ブロック動画（約 5 秒）を出力します。
