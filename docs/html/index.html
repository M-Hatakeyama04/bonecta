依頼の一言要約

go2senkyo.com の活動記録 URL から、SNS向け縦型ショート動画を自動生成したい。 すでに動くプロトタイプと確定仕様があるので、それを本番利用できる形に仕上げてほしい。

必須で守ってほしいこと: 素材タイプごとの表示ルール、テロップ有無、左上バッジ、エンドカード、 同梱フォント（Noto Sans JP）による見た目の固定。

発注前に発注者が決めること

  • スコープ（仕様準拠の生成のみ / API化 / 管理画面 / 本体統合 など）
  • 納期・予算感
  • サンプル MP4 の共有方法（Drive 等）
  • テロップをルール分割のままにするか、LLM 化するか
