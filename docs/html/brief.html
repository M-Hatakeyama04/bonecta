1. 依頼の目的

政治家・候補者の活動記録（ブログ記事）から、SNS投稿向けの 9:16 縦型ショート動画を自動生成する機能を依頼したい。

すでに動作する Python プロトタイプ と 確定した画面仕様 がある。 主目的は、これを本番利用できる形に仕上げ・統合・運用可能にすること。

期待する価値

  • 活動記録 URL を入れるだけで、投稿用ショート動画が得られる
  • 素材タイプに応じて正しい見せ方になる
  • バッジ・テロップ・エンドカードがブランドとして統一されている
  • 生成結果が端末・環境によらず同じ見た目になる（フォント焼き込み）

2. 現状（プロトタイプ）

できていること

  • go2senkyo.com 記事のスクレイプ（本文、政治家名、フリガナ、年齢、ポートレート、素材）
  • 素材種別に応じた取得・表示分岐
  • テロップ生成・オーバーレイ（左上バッジ／字幕／エンドカード）
  • FFmpeg による MP4 出力（1080×1920）
  • 18 パターンのバッチ検証セット

本番化で追加しうるスコープ

区分内容
A. プロダクト化API化、ジョブキュー、進捗・失敗通知、リトライ
B. 画面管理画面（URL入力→生成→プレビュー→ダウンロード）
C. 品質テスト自動化、ログ、監視、エラーハンドリング強化
D. 統合Bonecta 本体サービス／認証／ストレージとの接続
E. 運用デプロイ、並列生成、コスト設計
F. 文言テロップ要約の LLM 化（現状はルール分割）
必須要件は「動画の見た目・挙動仕様」。A〜F の発注範囲は見積時に指定する。

3. 成果物

必須

  1. 活動記録 URL（または同等入力）から 9:16 MP4 を生成できること
  2. 本依頼書および動画仕様書の表示ルール・UI に準拠すること
  3. サンプル 18 パターン相当の検証結果
  4. セットアップ手順・運用手順書
  5. ソースコード一式

任意（プロダクト化する場合）

  1. HTTP API（生成開始／状態取得／結果取得）
  2. 簡易 UI（プレビュー・ダウンロード）
  3. オブジェクトストレージへの成果物保存
  4. ジョブ失敗時の通知・再実行

4. 機能要件

4.1 入力

  • go2senkyo.com の活動記録 URL
    https://go2senkyo.com/seijika/{id}/posts/{post_id}
  • （将来）Bonecta 側の活動記録 ID / 内部 API

4.2 抽出する情報

情報用途
記事タイトル・本文テロップ生成
政治家氏名バッジ・エンドカード
フリガナ / 年齢 / 性別バッジメタ行
ポートレート画像バッジ・エンドカード・フォールバック
本文画像本編スライド
直接動画（mp4 等）本編（優先）
YouTube / FB / IG 埋め込みルールに従いサムネ or ポートレート

4.3 本編表示ルール（必須）

#条件表示テロップ
1画像のみ画像あり
2画像なし・動画なし政治家画像あり
3画像 + 直接動画直接動画なし
4直接動画のみ直接動画なし
5YouTube（VOD）サムネイル（横幅全表示）あり
6YouTube Live政治家画像あり
7Facebook / Instagram政治家画像あり
  • 「動画」は直接アップロードのみ。埋め込み動画本体のダウンロード・再配布はしない
  • YouTube 通常は公式サムネイルを使い、横を切らない
  • 画像は最大 5 枚。切替は 0.5 秒クロスフェード

4.4 テロップ

  • 最大 5 枚 × 4 秒、1 枚あたり最大 24 文字目安
  • 最終枚に「……（続く）」
  • 白半透明背景 + 緑枠 2px + 黒文字
  • 同梱 Noto Sans JP、weight 500
  • 文字は動画に焼き込む

4.5 左上バッジ

  • 緑ピル、円形ポートレート、氏名（Bold）、フリガナ/年齢/性別
  • 余白: 左右 22px 前後、上下 12px 前後

4.6 エンドカード

  • 円形ポートレート + 緑リング（隙間なく密着）
  • 「{名前}」「情報発信中！」
  • CTA: 「続きは活動記録をチェック」+ >（縦中央）
  • 免責文を下部に表示。ヘッダー帯は置かない

4.7 音声

  • 直接動画に音声がある → 動画音声優先
  • それ以外 → BGM

5. 非機能要件

項目要件
見た目の再現性同梱フォントのみ。環境差で字形が変わらないこと
依存Python 3.11+、FFmpeg / ffprobe、Pillow、requests、BeautifulSoup
性能1 本あたり数分以内を目標
信頼性一部素材失敗時も可能な範囲で継続
ログ失敗理由が追えること
セキュリティ秘密情報をリポジトリに含めない

7. 受け入れ条件

  1. 1080×1920 の MP4 が出力される
  2. 素材表示ルール（§4.3）を満たす
  3. 直接動画本編ではテロップが出ない
  4. YouTube VOD はサムネ表示、横幅が切れない
  5. YouTube Live / FB / IG は政治家画像 + テロップ
  6. 左上バッジ・エンドカードが仕様どおり
  7. フォントは同梱 Noto Sans JP（テロップ weight 500）
  8. 仕様書チェックリストを通過
  9. 代表パターンの確認動画を提出
  10. ソース・手順書・依存一覧を納品
