## 1. 依頼の目的

政治家・候補者の **活動記録（ブログ記事）** から、SNS投稿向けの **9:16 縦型ショート動画** を自動生成する機能を、開発会社に依頼したい。

すでに動作する **Python プロトタイプ** と **確定した画面仕様** がある。  
依頼の主目的は、これを **本番利用できる形に仕上げ・統合・運用可能にする** ことである。

### 期待する価値

- 活動記録 URL を入れるだけで、投稿用ショート動画が得られる
- 素材タイプ（画像／直接動画／YouTube／SNS埋め込み）に応じて、正しい見せ方になる
- 見た目・テロップ・エンドカードがブランドとして統一されている
- 生成結果が端末・環境によらず同じ見た目になる（フォント焼き込み）

## 2. 現状（プロトタイプ）

### できていること

- go2senkyo.com 記事のスクレイプ（本文、政治家名、フリガナ、年齢、ポートレート、素材）
- 素材種別に応じた取得・表示分岐
- テロップ生成・オーバーレイ（左上バッジ／字幕／エンドカード）
- FFmpeg による MP4 出力（1080×1920）
- 18 パターンのバッチ検証セット

## 4. 機能要件

### 4.1 入力

- go2senkyo.com の活動記録 URL  
  例: `https://go2senkyo.com/seijika/{id}/posts/{post_id}`
- （将来）Bonecta 側の活動記録 ID / 内部 API

### 4.2 抽出する情報

| 情報 | 用途 |
|------|------|
| 記事タイトル・本文 | テロップ生成 |
| 政治家氏名 | バッジ・エンドカード |
| フリガナ / 年齢 / 性別 | バッジメタ行 |
| ポートレート画像 | バッジ・エンドカード・素材フォールバック |
| 本文画像 | 本編スライド |
| 直接動画（mp4 等） | 本編（優先） |
| YouTube / FB / IG 埋め込み | ルールに従いサムネ or ポートレート |

### 4.3 本編表示ルール（必須）

| # | 条件 | 表示 | テロップ |
|---|------|------|----------|
| 1 | 画像のみ | 画像 | あり |
| 2 | 画像なし・動画なし | 政治家画像 | あり |
| 3 | 画像 + 直接動画 | 直接動画 | **なし** |
| 4 | 直接動画のみ | 直接動画 | **なし** |
| 5 | YouTube（VOD） | サムネイル（横幅全表示） | あり |
| 6 | YouTube Live | 政治家画像 | あり |
| 7 | Facebook / Instagram | 政治家画像 | あり |

補足:

- 「動画」は **直接アップロードのみ**。埋め込み動画ファイルのダウンロード・再エンコード再生はしない
- YouTube 通常埋め込みは **公式サムネイル** を使い、横を切らない（pillarbox）
- 画像は最大 5 枚。切替は 0.5 秒クロスフェード

### 4.4 テロップ要件

- 本文をルール分割（または将来 LLM 要約）
- 最大 5 枚 × 4 秒、1 枚あたり最大 24 文字目安
- 最終枚に「……（続く）」
- 白半透明背景 + 緑枠 2px + 黒文字
- フォント: 同梱 Noto Sans JP、weight **500**
- **文字は動画に焼き込む**（再生側フォントに依存しない）

### 4.5 左上バッジ要件

- 緑ピル、円形ポートレート、氏名（Bold）、フリガナ/年齢/性別
- 余白: 左右 22px 前後、上下 12px 前後（過度に広くしない）

### 4.6 エンドカード要件

- 円形ポートレート + 緑リング（隙間なく密着）
- 「{名前}」「情報発信中！」
- CTA: 「続きは活動記録をチェック」+ `>`（**縦中央**）
- 免責: 「この動画はボネクタの活動記録に基き、AIで生成しています。」
- ヘッダー帯は置かない

### 4.7 音声

- 直接動画に音声がある → 動画音声優先
- それ以外 → BGM（`bgm/`）

## 5. 非機能要件

| 項目 | 要件 |
|------|------|
| 見た目の再現性 | 同梱フォントのみ使用。環境差で字形が変わらないこと |
| 依存 | Python 3.11+ 想定、FFmpeg / ffprobe、Pillow、requests、BeautifulSoup |
| 性能 | 1 本あたり数分以内を目標（素材・動画長に依存） |
| 信頼性 | 一部素材取得失敗時も、可能な範囲で生成継続 |
| ログ | 失敗理由が追えること（URL、素材 ID、例外） |
| セキュリティ | 秘密情報をリポジトリに含めない。スクレイプは公開ページ想定 |

## 7. 受け入れ条件（Acceptance Criteria）

### 見た目・挙動

1. 1080×1920 の MP4 が出力される
2. 素材表示ルール（§4.3）を満たす
3. 直接動画本編ではテロップが出ない
4. YouTube VOD はサムネ表示、横幅が切れない
5. YouTube Live / FB / IG は政治家画像 + テロップ
6. 左上バッジ・エンドカードが仕様どおり
7. フォントは同梱 Noto Sans JP（テロップ weight 500）

### 検証

8. `docs/VIDEO_SPEC.md` のチェックリストを通過
9. バッチ相当パターン（最低でも画像のみ／なし／YouTube／FB／直接動画）で確認動画を提出

### 納品

10. ソース・手順書・依存一覧
11. （API 発注時）OpenAPI または同等の API 仕様
