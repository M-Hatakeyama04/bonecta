# Bonecta ショート動画 仕様書

go2senkyo.com の活動記録（ブログ記事）から **9:16 縦型ショート動画** を生成する際の参照仕様。  
実装の正は `bonecta/` 配下のコード。本書は運用・レビュー用の要約。

---

## 1. 出力仕様

| 項目 | 値 |
|------|-----|
| 解像度 | **1080 × 1920**（9:16） |
| フレームレート | 30 fps |
| コーデック | H.264 / yuv420p（FFmpeg） |
| 本編尺 | 最大 **20 秒**（テロップあり時）／直接動画時は最大 **15 秒** |
| エンドカード | **3 秒**（クロスフェード 0.5 秒含む） |
| 合計尺 | おおよそ **22〜23 秒** |

---

## 2. 処理パイプライン

```
go2senkyo URL
  → scraper.py      … HTML から本文・政治家情報・素材 URL を抽出
  → media_fetcher.py … 画像 / 動画 / サムネをローカル取得
  → analyzer.py     … MediaAsset 化・パターン分類・安全チェック
  → composer.py     … タイムライン・テロップ ON/OFF を決定
  → overlays.py     … バッジ・テロップ・エンドカード PNG を生成
  → renderer.py     … FFmpeg で合成 → MP4
```

### コマンド

```bash
# 1 本（スクレイプから）
python scripts/batch_go2senkyo.py   # 未生成のみ

# 全本・再生成
python scripts/batch_go2senkyo.py --force

# 既存 post.json + media から再レンダーのみ（スクレイプなし）
# → output/go2senkyo/{slug}/post.json と media/ が前提
```

### 出力ディレクトリ（1 記事あたり）

```
output/go2senkyo/{slug}/
  {slug}.mp4          … 完成動画
  post.json           … スクレイプ結果・素材メタ
  ffmpeg_plan.json    … レンダリング計画（デバッグ用）
  media/              … 取得済み画像・動画
  .work/              … 中間ファイル（オーバーレイ PNG 等）
```

## 3. 素材の表示ルール（本編）

「動画」= 記事内の **直接アップロード動画**（`<video>` / `.mp4`）。  
YouTube・Facebook・Instagram の **埋め込みは動画本体を使わない**。

| 記事の内容 | 本編に表示するもの | テロップ |
|------------|-------------------|----------|
| 画像のみ | ブログ画像（最大 5 枚スライド） | **あり** |
| 画像なし・動画なし | 政治家ポートレート | **あり** |
| 画像 + 直接動画 | **直接動画のみ**（画像は使わない） | **なし** |
| 直接動画のみ | 直接動画 | **なし** |
| YouTube（通常） | **YouTube 公式サムネ**（横幅切れない pillarbox） | **あり** |
| YouTube Live | 政治家ポートレート | **あり** |
| Facebook / Instagram 埋め込み | 政治家ポートレート | **あり** |
| 画像 + YouTube 等 | 画像 + サムネ／ポートレート（直接動画がなければ画像系） | **あり** |

### 素材取得（`media_fetcher.py`）

- **画像** … 本文中の `<img>` をダウンロード
- **直接動画** … mp4 をダウンロード・ffprobe で長さ・音声有無を取得
- **YouTube** … `resolve_youtube_thumbnail` でサムネ JPG（Live はポートレート）
- **Facebook / Instagram** … 政治家ポートレートを `embed_thumbnail` として使用
- **フォールバック** … 利用可能素材がなければ `portrait_fallback.jpg`

直接動画がある記事では、ブログ画像のダウンロード自体をスキップする。

## 4. レイアウト・画像の見せ方

### 4.1 共通

- **背景ウォッシュ** … `#ECECE0` 相当を **背景レイヤーのみ** に薄く敷く（前景の写真・UI にはかけない）
- **横長・小さい画像** … ぼかし背景（pillarbox）+ 中央に前景
- **縦長画像** … 全画面に近い表示（小サイズは pillarbox）
- **切替** … 0.5 秒クロスフェード。複数枚時は先頭 0.5 秒だけズームイン可

### 4.1.1 画角プリセット（`crop_preset`）

| プリセット | 用途 |
|------------|------|
| `default` | 標準。YouTube サムネは **常に default**（横幅全体を見せる） |
| `wide` | 1 枚ブログ画像の前半 |
| `close` | 1 枚ブログ画像の後半／FB・IG・OG サムネ等 |

### 4.2 左上バッジ（全編常時表示）

| 要素 | 仕様 |
|------|------|
| 形状 | 黄緑（`#70C040`）の角丸ピル、枠線なし |
| 左 | 円形アバター 96px（政治家ポートレート） |
| 右 | **名前**（白・Bold 42px）＋ **フリガナ / 年齢 / 性別**（白・36px） |
| 余白 | 左右 22px、上下 12px、アバターと文字の間 14px |
| 位置 | 左上 `(28, 40)` 付近 |

政治家メタはプロフィールページから `name_reading`・`age`・`gender` を補完。

## 5. テロップ（字幕）

### 5.1 表示条件

- **テロップあり** … 画像系本編のみ（上表参照）
- **テロップなし** … 直接動画が本編にある場合

### 5.2 文案

- ブログ本文を **整形せず** 句読点で分割（`telop.py`）
- 1 枚 **最大 24 文字**、**最大 5 枚**
- 1 枚 **4 秒** → 本編最大 **20 秒**
- 最終枚は **「……（続く）」** を付与（既に続き表現があればそのまま）
- URL は除去

### 5.3 見た目

| 項目 | 値 |
|------|-----|
| 位置 | 画面高さの **62%** 付近を中心 |
| 箱 | 白半透明 `rgba(255,255,255,200)`、角丸 14px |
| 枠 | 黄緑 **2px**（`#70C040`） |
| 文字色 | `#222222` |
| 字間 | 1px（軽さのため） |
| フォントサイズ | 32〜50px（箱幅に自動フィット） |
| パディング | 横 30px / 縦 18px |

### 5.4 フォント

| 用途 | フォント | weight |
|------|----------|--------|
| テロップ | 同梱 **Noto Sans JP VF** | **500** |
| バッジ名前・CTA | 同上 | **700** |
| メタ・注釈 | 同上 | **400** |

- ファイル: `fonts/NotoSansJP-VF.ttf`
- **OS フォントへのフォールバックなし**（端末・ブラウザ差を出さないため、文字はすべて生成時に画像化して MP4 に焼き込み）

---

## 6. エンドカード（末尾約 3 秒）

| 要素 | 仕様 |
|------|------|
| 背景 | 政治家肖像のぼかし + `#ECECE0` ウォッシュ（**UI の背面のみ**） |
| 中央上 | 円形アバター **340px** + 緑リング **12px**（写真と密着） |
| 名前 | 黒・太字・最大 72px（幅に応じて縮小） |
| 文言 | **「情報発信中！」**（黒・56px 目安） |
| CTA | 緑ピル **「続きは活動記録をチェック」** + 図形シェブロン `>`（縦中央揃え） |
| フッター | **「この動画はボネクタの活動記録に基き、AIで生成しています。」**（グレー・26px） |

トップの帯（ヘッダーバー）は **なし**。

## 7. カラーパレット

| 名前 | 値 | 用途 |
|------|-----|------|
| 選挙ドットコム緑 | `#70C040` (112,192,64) | バッジ・テロップ枠・CTA・リング |
| 緑（濃） | `#589E30` (88,158,48) | CTA 縁取り |
| 本文黒 | `#222222` | テロップ・エンドカード名前 |
| サブグレー | `#5A5A5A` | 注釈 |
| ページ背景 | `#ECECE0` (236,236,224) | 背景ウォッシュ |

政党色（`party_color`）はエンドカード以外では主にフォールバック背景に使用。

---

## 8. 音声

| 条件 | 音声 |
|------|------|
| 直接動画に音声あり | **動画の音声を優先**（BGM は下げる／ミュート） |
| それ以外 | `bgm/` からランダム BGM |

---

## 9. 安全・ブロック

`analyzer.check_content_safety` で NG の場合、本編・テロップなしの短尺ブロック動画（約 5 秒）を出力。

## 10. 調整時の参照ファイル

| 変更したい内容 | ファイル |
|----------------|----------|
| 表示ルール・尺・テロップ ON/OFF | `bonecta/composer.py` |
| 素材取得・YouTube/FB/IG | `bonecta/media_fetcher.py` |
| バッジ・テロップ・エンドカード見た目 | `bonecta/overlays.py` |
| テロップ文案・枚数・文字数 | `bonecta/telop.py` |
| フォント weight | `bonecta/fonts.py` |
| FFmpeg 合成・レイアウト | `bonecta/renderer.py` |
| 一括 URL リスト | `scripts/batch_go2senkyo.py` |

## 11. レビュー用チェックリスト

動画を確認するときの目安:

- [ ] 素材種別に応じた表示（上表）になっているか
- [ ] 直接動画時にテロップが **出ていない** か
- [ ] YouTube サムネの **横幅が切れていない** か
- [ ] 左上バッジにフリガナ・年齢が入っているか
- [ ] テロップが読みやすく、最終枚に「……（続く）」があるか
- [ ] エンドカードの CTA・円写真・注釈が意図どおりか
- [ ] フォントが野暮ったくないか（Noto 500）

## 12. バッチ検証セット

`scripts/batch_go2senkyo.py` に **18 パターン** を定義。代表例:

| slug | 検証内容 |
|------|----------|
| `01_images_landscape` | 横画像 + テロップ |
| `07_no_images_no_thumb` | ポートレートのみ |
| `08_video_youtube_landscape_1` | YouTube サムネ |
| `11_video_portrait` | Facebook → ポートレート |
| `13_mixed_img_portrait_video` | 画像 + 埋め込み（直接動画なし） |
| `17_special_live` | YouTube Live → ポートレート |
